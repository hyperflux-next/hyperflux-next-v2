# Getting help

1. Run `hyperfluxctl doctor` and follow its advice.
   [Troubleshooting](docs/user/troubleshooting.md) has a section for
   every code it prints.
2. Check the [known limitations](docs/user/limitations.md).
3. Ask in [Discussions](https://github.com/hyperflux-next/hyperflux-next-v2/discussions),
   or open a [bug report](https://github.com/hyperflux-next/hyperflux-next-v2/issues/new?template=bug_report.yml)
   with the Doctor output and `hyperfluxctl support-bundle --preview`.

Problems with OpenRazer, Polychromatic or OpenRGB themselves that also
happen with a cable belong to those projects.

This is a volunteer project. Answers can take a few days. Security
problems go through [SECURITY.md](SECURITY.md), not public issues.
